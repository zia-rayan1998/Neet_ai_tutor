# NEET AI Tutor

A Chrome extension that helps you prepare for NEET by giving **hint-by-hint** explanations, full solutions, summaries, and mind maps — directly on any webpage.

Instead of just giving answers, it teaches you step by step so you actually learn.

---

## Features

- Floating green **“N”** button that stays on every page
- Select any question → Analyze → Get help
- **Hint** (gentle first hint)
- **Next Hint**
- **Full Solution** (step-by-step + final answer + common mistakes)
- **Summarize** long paragraphs
- **Mind Map** generation
- Simple and student-friendly language
- Formulas written in easy-to-read format
- Works with text selection (no need to copy-paste)

---

## Installation (Load Unpacked)

1. Download or clone this repository
2. Open Chrome and go to `chrome://extensions/`
3. Turn on **Developer mode** (top right)
4. Click **Load unpacked**
5. Select the project folder (`neet-ai-tutor`)
6. The extension is now installed

---

## How to Use

1. Click the extension icon and toggle it **ON**
2. A green circular **“N”** logo will appear on the bottom-right of every page
3. Go to any NEET question page
4. **Select** the question text with your mouse
5. Click the green **N** logo
6. Click **Analyze Selected**
7. Then choose:
   - Give Hint
   - Next Hint
   - Full Solution
   - Summarize
   - Mind Map

You can close the panel anytime. The small logo will stay on the page until you turn the extension OFF.

---

## Getting a Free API Key (Groq)

This extension uses Groq’s free API.

1. Go to [https://console.groq.com](https://console.groq.com)
2. Sign up / Log in
3. Go to **API Keys** → Create API Key
4. Copy the key (it starts with `gsk_...`)
5. When the extension asks for the API key, paste it

The key is stored locally in your browser and is never shared.

## Notes

- The extension only works when it is toggled **ON**
- Always **select the question** before clicking “Analyze Selected”
- Answers are generated by AI — always double-check important concepts with your NCERT books
- Free Groq models have rate limits. If you hit a limit, wait a few seconds and try again
